# Data Structures

Implementations of useful data structures.

Each project lives in its own subdirectory with a `README.md` and a runnable `solution.py`.

- [Inverted Index](Inverted-Index/) — An Inverted Index is a data structure used to create full text search. Given a set of text files, implement a program to create an inverted index. Also create a user interface to do a search using that inverted index which returns a list of files that contain the query term / terms. The search index can be in memory.

## Running a project

```bash
cd <Project-Directory>
python3 solution.py --demo
```

Every program supports `--help`; most run interactively with no arguments. Image-based projects list Pillow in `requirements.txt`.
