# Python Solutions

Implementations of the [Mega Project List](README.md) in Python, organized by
the same categories as the original list. Every project has its own directory
with a `README.md` (problem statement, usage, sample output) and a runnable
`solution.py`.

**92 projects across 13 categories.**

## Running a project

```bash
cd <Category>/<Project-Directory>
python3 solution.py --demo     # scripted, non-interactive demonstration
python3 solution.py --help     # all available options
```

Image-based projects need Pillow: `pip install -r requirements.txt`.
